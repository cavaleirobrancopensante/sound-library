# Sound library

Giulliano's (Salgarellius') sounds and real instrument recordings, gathered while making Triumviwar, kept here for any
future game. Every file was supplied by him; this repository only sorts them.

## Licences (read before using a file in a game you sell)

- **Pixabay** (Pixabay Content Licence: free for commercial use, no credit needed): every sound effect, the marching
  drums, the fife, bugle, timpani, brass, strings, keyboard and waltz recordings (per the owner, 2026-11-14: "it's all
  pixabay"). Pixabay does not allow re-selling or re-distributing the files on their own as a sound pack.
- **FreePats Bagpipe** (`instruments/bagpipe_freepats/`): Gilles Sadowski, **CC0** (public domain). LICENSE.txt.
- **MuldjordKit drum kit** (`instruments/drum_kit_muldjord/`): Lars Muldjord, **CC BY 4.0**: CREDIT REQUIRED in the game,
  e.g. "MuldjordKit drum samples by Lars Muldjord, CC BY 4.0". LICENSE.txt, README.txt; MuldjordKit.sfz maps the hits.
- **Voices** (`voices/`): his own ElevenLabs recordings (the King, the Crown herald, the Brood scientist, unit lines).
- Notes cut from recordings: `instruments/fife/notes/` (9 fife notes, MIDI number names) and `instruments/bugle/notes/`
  (bugle harmonics h2-h6), cut by Triumviwar's tools/audio/fife_sampler.py and bugle_sampler.py.
